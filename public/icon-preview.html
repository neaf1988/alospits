A Los Pits — 3 opciones de icono

Compara cómo se ven en distintos tamaños. Dime cuál prefieres (A, B o C).

Opción A — Pit Lane

Auto en boxes con bandera a cuadros. Evoca “Los Pits” y carrera.

option-a-pit-lane.svg

Opción B — Llanta / km

Neumático con odómetro. Conecta con labrado, km y mantenimiento.

option-b-tire.svg

Opción C — Monograma P

Letra P sobre carril. Limpio, legible en pantalla de inicio.

option-c-monogram.svg
Para aplicar la que elijas: copia el SVG elegido sobre public/icon-source.svg y ejecuta npm run icons:generate seguido de npm run build.
